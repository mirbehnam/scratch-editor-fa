# گزارش حذف آموزش داخلی Scratch GUI

این تغییر بنا به درخواست صاحب پروژه در شاخهٔ `my-develop` انجام شد. حذف، سورس و همهٔ خروجی‌های GUI را شامل می‌شود؛ اسپرایت‌ها، لباس‌ها، پس‌زمینه‌ها، صداها، فونت و بریج‌های اندروید حفظ شده‌اند.

## مبنا و روش بررسی

- مبنای قبل از تغییر: `b1e46a737ff274ea56d79c2ed37eb146babbe2e0`.
- [نقطهٔ بازیابی ساخته‌شده روی سرور](https://github.com/mirbehnam/scratch-editor-fa/releases/tag/restore-point-my-develop-b1e46a737ff274ea56d79c2ed37eb146babbe2e0).
- ۱۵۱۵ فایل حذف شد: ۱۴۸۷ تصویر/آیکون و ۲۸ فایل کد، استایل، تست و snapshot.
- ارجاع‌های فایل‌های ثبت‌شدهٔ monorepo بررسی و هفت وابستگی بیرونی کد آموزش پیش از حذف قطع شد. هیچ تصویر آموزشی با مصرف‌کنندهٔ غیرآموزشی پیدا نشد.
- هش هر فایل بلافاصله پیش از حذف کنترل شد و فهرست حذف‌های گیت دقیقاً با گزارش تطبیق داده شد.
- [گزارش ماشینی شامل مسیر، اندازه، SHA256 و ارجاع‌های جداشده](../packages/scratch-gui/scripts/tutorial-removal-audit.json).

## کد حذف‌شده از فایل‌های باقی‌مانده

مسیرهای این جدول نسبت به `packages/scratch-gui` هستند.

| فایل | بخش حذف‌شده |
| --- | --- |
| `src/components/gui/gui.jsx` | import و نمایش Cards/TipsLibrary و props آموزشی `cardsVisible`، `tipsLibraryVisible`، `onTutorialSelect` و `hideTutorialProjects` |
| `src/containers/gui.jsx` | اتصال QueryParserHOC و نگاشت وضعیت/props آموزش |
| `src/reducers/gui.ts` | import محتوای درس‌ها، state و reducer کارت‌ها و تابع `initTutorialCard` |
| `src/reducers/modals.js` | شناسه و state پنجرهٔ tipsLibrary و توابع `openTipsLibrary` و `closeTipsLibrary` |
| `src/exported-reducers.ts` | exportهای اختصاصی آموزش: `activateDeck`، `openTipsLibrary` و `closeTipsLibrary` |
| `src/components/library/library.jsx` | وابستگی به decks، چهار عنوان دستهٔ درس‌ها، گروه‌بندی مختص آموزش و prop داخلی `withCategories` که تنها مصرف‌کننده‌اش tips library بود |
| `src/components/library/library.css` | سه استایل دسته‌های درس: `library-category`، `library-category-title` و `library-category-items` |
| `eslint.config.mjs` | استثنای lint مربوط به فایل‌های تولیدشدهٔ decks |
| `src/css/z-index.css` | اشارهٔ منسوخ آموزش در توضیح ترتیب لایه‌ها؛ مقدار لایه تغییر نکرد |

APIهای آموزشی یادشده عمداً از این fork حذف شده‌اند. سایر exportها حفظ شده‌اند. پارامتر `?tutorial=...` دیگر آموزش را فعال نمی‌کند و ساختار SB3 تغییری نکرده است.

## موارد مهمی که حفظ شدند

- همهٔ کتابخانه‌های اسپرایت، لباس، پس‌زمینه و صدا و ۱۳۴۷ رسانهٔ موردنیاز آن‌ها.
- تمام ۱۳۹۲ فایل غیرآموزشیِ قبلی در `build/static/assets` با SHA256 یکسان.
- `react-draggable`، چون monitorهای متغیرها به آن نیاز دارند.
- `src/lib/settings/color-mode/high-contrast/blocks-media/icons/arrow_button.svg`، با وجود واژهٔ Tutorials در شناسهٔ SVG؛ این فایل جزو رسانه‌های بلوک‌هاست.
- کتابخانهٔ عمومی، فیلتر، جست‌وجوی فارسی/انگلیسی، برچسب‌ها و پیش‌نمایش رسانه‌ها.
- بستهٔ مشترک ترجمه‌ها، فونت یکان، اصلاحات RTL، دیالوگ‌ها و بریج‌های اندروید.

## کنترل خروجی و آزمون‌ها

کنترل جدید `scripts/verify-offline-build.js` با هش تصاویر حذف‌شده، بازگشت آن‌ها به بیلد بهینه را تشخیص می‌دهد. روی خروجی قدیمی خطا داد و روی خروجی جدید موفق شد. فهرست رسانه‌های اصلی، فونت، بریج‌ها و اسکریپت‌های sandbox نیز همچنان کنترل می‌شوند.

- بیلد استاندارد GUI و بیلد آفلاین و نصب‌کننده‌های Windows x64/ia32 موفق بودند.
- ۶۹ مجموعهٔ Jest با ۳۹۸ تست و ۱۳ snapshot موفق بودند؛ یک تست skip است.
- ESLint خطا ندارد؛ هشدارهای سبک موجود باقی‌اند. استخراج منبع i18n اجرا شد.
- انتخاب واقعی اسپرایت، لباس، پس‌زمینه و صدا در مرورگر با اینترنت خارجی مسدود موفق بود؛ جست‌وجوی انگلیسی در رابط فارسی نیز بررسی شد.
- ورود به ویرایشگر نقاشی، ذخیره و بازکردن SB3، نبود فایل مفقود/خطای صفحه و بی‌اثرشدن `?tutorial=all` تأیید شد.
- خط دور بلوک در فارسی، عربی و انگلیسی بررسی شد. آزمون روی گوشی و اجرای تعاملی خود Electron در این مرحله تکرار نشده است.
